# Odd Orbit

한국어 과학책 큐레이션 웹사이트. 전달받은 홈페이지와 이미지 11개를 기반으로 기존 매거진 레이아웃, 색상, 아트워크를 유지했습니다.

## 실행

별도 패키지 설치나 빌드가 필요하지 않습니다. 기존 `/workspace/261104` 체크아웃을 사용합니다.

```sh
cd /workspace/261104
python -m http.server 8000 --bind 127.0.0.1
```

다른 프로세스가 이미 해당 포트를 사용한다면 종료하지 말고 다른 포트를 선택하세요. 서비스 프로세스는 환경 복원 후 다시 시작해야 합니다.

- `index.html`: 홈페이지, 반응형 CSS, 모달 및 퀴즈 화면
- `quiz.js`: 6문항, 가중치, 점수 계산, 추천 도서 데이터 (브라우저와 Node.js 공용)
- `assets/`: 제공받은 원본 PNG 11개
- `tests/`: 점수 계산과 브라우저 회귀 검증
- `Odd_Orbit_preview.html`: 이미지와 코드를 포함해 브라우저에서 바로 열 수 있는 단일 HTML

단일 HTML을 최신 소스로 다시 만들려면 저장소 루트에서 실행하세요.

```sh
python scripts/export_preview.py
```

책 제목은 〈나무들의 비밀스러운 생활〉로 수정했습니다. 실제 표지 교체는 아직 완료하지 않았으며, 현재 이미지에는 처음 전달받은 아트워크가 사용됩니다.

Google Fonts는 선택적으로 사용하며 로드되지 않으면 시스템 sans-serif 글꼴로 표시됩니다. 답변은 현재 페이지 메모리에만 유지되며 서버에 전송하거나 저장하지 않습니다.

## 테스트

Node.js로 전체 4,096개 응답 조합, 동점 후보 보존, 입력 검증, 20유형별 추천 도서 조합을 검증합니다.

```sh
node tests/quiz.test.js
```

로컬 서버를 실행한 상태에서 Playwright와 Chromium으로 모바일/데스크톱 레이아웃, 키보드 조작, 검색, 20개 결과 유형, 추천 도서, 재시작, 기존 상세 모달을 검증합니다. 현재 클라우드에는 Playwright와 `/usr/bin/chromium`이 설치되어 있습니다. 다른 환경에서는 이 두 도구를 먼저 준비하세요. 브라우저 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다.

```sh
node tests/browser.cjs
```

브라우저 검증은 포트 8000을 사용하며 스크린샷을 `/tmp/odd-orbit-desktop.png`, `/tmp/odd-orbit-mobile.png`에 저장합니다. 컨테이너의 Chromium 실행에는 `--no-sandbox`를 사용합니다.

## 결과 규칙과 수정 내용

- 원래의 6문항과 선택지 가중치를 유지합니다. 분야와 성향은 각각 점수 합계의 최댓값으로 결정합니다.
- 공동 1위가 있으면 동점 후보를 모두 표시하고 사용자가 직접 선택합니다. 배열 순서로 결과를 확정하지 않습니다. 이 방식으로 지구과학 실험가를 포함한 20유형이 모두 도달 가능합니다.
- 각 분야에 도서 4권을 두고 성향에 따라 서로 다른 3권 조합과 읽기 안내를 제공합니다. 20유형의 추천 도서 조합은 서로 다릅니다.
- 막대는 답변 가중치 합계를 표시하며 공통 상한인 12점을 기준으로 그립니다. 적성이나 확률을 뜻하지 않습니다.
- 추천 도서 더 보기는 해당 결과의 책장을 열고, 결과 화면으로 돌아갈 수 있습니다.
- 책장만 내부 가로 스크롤을 허용하고 페이지의 가로 넘침을 해결했습니다. 아트워크는 잘리지 않도록 contain으로 표시합니다.
- 모달에 제목 연결, 배경 비활성화, Tab 순환, Escape 닫기와 호출 버튼 포커스 복귀를 적용했습니다. 선택지 클릭 시 포커스와 스크롤 위치를 유지합니다.

제공된 ZIP에는 `AGENTS.md`, 별도 기획서와 승인된 디자인 시안이 없었습니다. 따라서 시안과의 일치 여부는 검증하지 않았습니다. 외부 서점의 실제 검색 결과 및 도서 재고는 자동 테스트 범위에 포함하지 않습니다. 추천은 편집 가설이며 검증된 심리검사가 아닙니다.
